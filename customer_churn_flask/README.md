# Customer Churn Prediction — Flask Project

A beginner-friendly Flask web application that predicts whether a telecom customer is likely to leave. It uses the real IBM Telco Customer Churn CSV dataset, a scikit-learn preprocessing pipeline, and logistic regression classification.

## What is included

- `app.py` — Flask web server and prediction route.
- `train_model.py` — cleans the dataset, trains the model, evaluates it, and saves the pipeline.
- `data/Telco-Customer-Churn.csv` — IBM Telco Customer Churn dataset.
- `model/churn_pipeline.joblib` — trained model generated by the training script.
- `model/metrics.json` — holdout accuracy and ROC-AUC metrics.
- `templates/` and `static/` — the web interface.

## Run it in VS Code

1. Extract the ZIP file and open the extracted `customer_churn_flask` folder in VS Code. Use **File → Open Folder**.
2. Open the VS Code terminal with **Terminal → New Terminal**.
3. Create a virtual environment:

   **Windows PowerShell**
   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```

   **macOS/Linux**
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```

4. Install the packages:

   ```bash
   pip install -r requirements.txt
   ```

5. Optional but recommended: retrain the model yourself:

   ```bash
   python train_model.py
   ```

6. Start the Flask app:

   ```bash
   python app.py
   ```

7. Open **http://127.0.0.1:5000** in your browser.

## How the model works

The target column is `Churn`, where `Yes` is converted to `1` and `No` to `0`. `TotalCharges` is converted from text to numeric values. Numeric columns are imputed and standardized. Categorical columns are one-hot encoded. The model is logistic regression with balanced class weights, which is a clear and explainable classification baseline for a student project.

The app shows the predicted churn probability. A probability of 50% or higher is labeled **Likely to churn**.

## Suggested project explanation

> This project predicts customer churn using supervised classification. The historical customer records contain demographics, services, contract type, billing information, and the known churn outcome. I cleaned missing values, transformed categorical features using one-hot encoding, scaled numeric features, and trained a logistic regression classifier. The Flask interface collects customer details and sends them through the same saved pipeline to produce a churn prediction and probability.

This dataset is fictional telecom customer data intended for analytics and learning. Do not use this demo model to make automatic decisions about real customers without validation, monitoring, privacy review, and human oversight.
